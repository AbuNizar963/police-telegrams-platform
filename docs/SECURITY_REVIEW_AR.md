## إصلاحات المراجعة

- **Service Worker:** حُصر الاعتراض في GET لأصول ثابتة فقط، مع منع تخزين استجابات `private` و`no-store` و`no-cache`، وحذف cache الإصدارات القديمة. أضيفت اختبارات تمنع التخزين للتنقل وواجهات API والتقارير.
- **صلاحيات البرقيات:** توحّدت قاعدة مهلة 48 ساعة بين الخادم والواجهة في دالة مختبرة؛ لم يعد دور الإدارة العادي يتجاوز المهلة مثل مالك النظام.
- **Cache الهاتف:** أضيف سجل محدود لمفاتيح cache الديناميكية كي يمسح التطبيق بيانات الجلسة عند فشل تعداد التخزين الآمن، مع اختبارات.
- **إعداد Supabase:** صُحح اسم المفتاح في التوثيق ليتوافق مع إعداد الخادم، مع تأكيد أنه خادمي فقط.
- **اعتماديات Node:** عولجت تنبيهات `body-parser` و`qs` بقيم دنيا مصححة وقفل محدث. أظهر `pnpm audit --audit-level=high` عدم وجود ثغرات معروفة.

تغطي اختبارات الانحدار رفض القائمة والتصدير والتقارير والإحصاءات والإشعارات عند غياب عضوية فعالة، وتستبعد الجهات المعطلة وأحفادها من القراءة الإقليمية، دون حجب إدارة الاستعادة.
