# دليل التشغيل والصيانة

## التشغيل المحلي

```bash
cp .env.example .env
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm build
pnpm dev
```

لا تُحفظ مفاتيح Supabase السرية أو كلمات المرور في Git. المتغيرات التي تبدأ بـ `VITE_` فقط مناسبة للواجهة.

## الصحة والنشر

- نقطة الصحة: `GET /api/health` ولا تكشف الأسرار.
- البناء: `pnpm build`.
- الفرع الإنتاجي: `main` بعد مراجعة Pull Request.
- راجع سجل Vercel وGitHub Actions قبل اعتماد الإصدار.
- للتراجع: أعد النشر من آخر commit ناجح، ولا تحذف migrations المطبقة.

## إشعارات المتصفح وPWA

النظام يستخدم مسارين متكاملين:

1. إشعار فوري محلي بعد تأكيد حفظ البرقية في نفس الجهاز.
2. Web Push في الخلفية للأجهزة والجهات المشتركة، عبر Service Worker حتى عند تثبيت التطبيق كـ PWA.

وللتفعيل في بيئة الإنتاج:

```bash
pnpm exec web-push generate-vapid-keys
```

ضع القيم الناتجة في Secrets الخادم، ولا تضع المفتاح الخاص في أي متغير `VITE_`:

- `VAPID_PUBLIC_KEY`
- `VAPID_PRIVATE_KEY`
- `VAPID_SUBJECT` مثل `mailto:security@example.gov`

بعد النشر يفتح الشرطي قائمة الإعدادات، يختار **تفعيل إشعارات البرقيات**، ثم يسمح بإشعارات المتصفح. يسجل النظام الاشتراك مربوطًا بالمستخدم والجهة، ويرسل إشعارًا عند إنشاء البرقية وعند إحالتها لوحدة أخرى. الاشتراكات المنتهية تُحذف تلقائيًا عند استلام رد `404` أو `410` من مزود الدفع.

إذا لم تظهر الإشعارات، تحقق من HTTPS، ومن عدم حظر إشعارات الموقع، ومن وجود `VAPID_PUBLIC_KEY` في استجابة إعدادات الإشعارات، ثم أعد تسجيل الاشتراك من القائمة.

## دورة البرقية

تنتقل البرقية عبر مسار الخادم فقط: مسودة → مرسلة للمراجعة → قيد المراجعة → معتمدة/معادة/مرفوضة → محالة → مكتملة → مؤرشفة. يمنع الخادم القفز بين الحالات ويطلب سببًا للإرجاع أو الرفض.

## المرفقات

المرفقات في bucket خاص، والروابط موقعة قصيرة العمر. تحفظ بيانات الملف، حجمه، نوعه، وبصمة SHA-256. حالة الفحص `unavailable` تعني أن الخدمة المضادة للبرمجيات الخبيثة غير موصلة بعد، ولا تعني أن الملف مُعتمد أمنيًا.

## الاستجابة للحوادث

1. أوقف الحساب أو دوّر `AUTH_SESSION_SECRET` عند الاشتباه بتسرب جلسات.
2. دوّر `SUPABASE_SECRET_KEY` من لوحة Supabase ولا تضعه في البلاغات.
3. راجع `audit_logs` و`telegram_actions`، واحتفظ بالنسخ الأصلية.
4. أوقف التصدير أو التنزيل مؤقتًا عند حادثة تسرب.
5. وثق الأثر والوقت والفاعل وخطة الرجوع.
