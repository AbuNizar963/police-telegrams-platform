# تقرير تنفيذ وثيقة التسليم

هذا الفرع هو `feat/delivery-report-hardening`، ومبني من الإصدار المتحقق الموجود على `main`. الهدف هو تحويل متطلبات وثيقة التسليم إلى تغييرات قابلة للاختبار دون تغيير `main` أو نشر أي شيء إلى نطاق Vercel غير معتمد.

## ما تم تنفيذه في هذا الفرع

| مجال التقرير                  | التنفيذ                                                                                                       | الدليل                                                                                |

## نتائج التحقق الأخيرة

- `pnpm check`: ناجح.
- `pnpm test`: ناجح، 20 اختبارًا.
- `pnpm build`: ناجح.
- اختبار محلي لـ `/api/health`: يعيد `200`.
- اختبار محلي لـ `/api/trpc/auth.me`: يعيد استجابة مصادق عليها بشكل صحيح عند غياب الجلسة (`null`) بدل خطأ خادم.
- `git diff --check`: ناجح.

## حدود يجب عدم إخفائها

1. طبقة التشغيل الحالية ما زالت تستخدم محول Drizzle/MySQL الموجود في القالب. Migration Supabase PostgreSQL موجودة ومراجعة كمخطط انتقال، لكنها لا تعني أن قاعدة الإنتاج تحولت تلقائيًا.
2. تفعيل Migration Supabase يحتاج بيئة اختبار مرتبطة بالمشروع، ثم تطبيقًا تدريجيًا ومراجعة فعلية لـ RLS وStorage قبل الإنتاج.
3. النسخ الاحتياطي والاستعادة الفعلية، وفحص البرمجيات الخبيثة، وقياسات الأداء، وتصدير التقارير حسب الجهة تحتاج بيئة تشغيل وبيانات اختبار معتمدة؛ لا يجوز الادعاء باجتيازها من اختبارات الوحدة فقط.
4. لا توجد أسرار أو مفاتيح إنتاج في هذا الفرع. يجب وضعها في Vercel/GitHub Secrets أو Supabase Vault حسب البيئة.
5. لا يحذف النظام الملفات اليتيمة تلقائيًا؛ يسجلها أولًا في `audit_logs` حتى يراجعها المسؤول وتُنفذ عملية تنظيف موثقة.
6. التخزين المحلي أو Supabase Storage ليسا مزودين مفعلين بعد؛ وجود الواجهة لا يعني نقل بيانات حقيقية أو تشغيلًا داخل مركز بيانات الوزارة.

## بوابة الدمج التالية

قبل دمج الفرع في `main`:

1. تشغيل Supabase محليًا أو في مشروع اختبار وتطبيق الـ migrations ثم `pnpm test:supabase`.
2. اختبار عزل جهتين بحسابين فعليين، ورفع/تنزيل مرفق من جلسة جديدة، وإعادة الاستعادة من نسخة احتياطية مع بصمات الملفات.
3. ربط Vercel بالحساب الشخصي الصحيح فقط، وضبط متغيرات Production/Preview، ثم اختبار `/api/health` وتدفق Google وتسجيل الدخول والحفظ بعد تحديث الصفحة.
