# مرجع تنسيق البرقية الرسمية

> هذا الملف هو **المرجع الرسمي** لإعدادات الطباعة والتصدير. لا تُعدّل القيم المذكورة هنا إلا بعد اختبار بصري فعلي للطباعة وPDF وPNG.

## الحالة الحالية — هدف 8K قيد التحقق

القيم التالية تصف **الإعداد المستهدف** لتصدير PNG بحد طويل قدره `7680px`، وليست اعتمادًا نهائيًا لجودة الناتج. لا يُعد تغيير الدقة معتمدًا بصريًا حتى تُنفّذ اختبارات Chromium الفعلية وتُراجع ملفات PDF وPNG الناتجة، بما في ذلك الشعار والعلامة المائية وCairo وRTL وحدود الذاكرة والاستجابة.

ما زالت معايير القبول المطلوبة هي:

- التأكد عمليًا من أن الطباعة تظهر في صفحة واحدة.
- التأكد من أن PDF يخرج بمقاس A4 من صفحة واحدة.
- قياس أبعاد PNG الفعلية وبيانات `pHYs` من ملف ناتج حقيقي.
- التأكد من ظهور العلامة المائية خلف محتوى البرقية داخل الصفحة نفسها.
- التأكد من تمركز المحتوى والورقة.
- فحص ظهور الشعار المضمّن دون كسر أو استبدال بشعار بديل.

**لا تُعتبر هذه النقاط متحققة بمجرد نجاح اختبارات الوحدة أو فحوصات CI.**

## الشعار والعلامة المائية

| الإعداد               |                                      القيمة/الإعداد الحالي |
| --------------------- | ---------------------------------------------------: |
| العلامة المائية النصية | 340 تكرارًا لعبارة `وزارة الداخلية` موزعة على كامل الورقة |
| توزيع النص            | شبكة `10 × 34`، وخط Cairo بحجم `11px`، وفجوة `5mm` أفقيًا ورأسيًا، وهامش داخلي للعلامة المائية `3mm` من حواف A4 |
| شفافية طبقتي العلامة  | إعداد مركزي للمالك؛ افتراضي `16%` وحد أعلى `60%` للنص والشعار معًا |
| شعار الجهة المائي     | بالمنتصف، `93.75%` من مساحة الورقة، وبشفافية الإعداد المركزي |
| ترتيب الطبقتين        | النص أسفل طبقة الشعار الوسطي (`z-index` أدنى)، وكلاهما خلف المحتوى |
| طبقة العلامة المائية  |                           خلف المحتوى (`z-index: 0`) |
| طبقة المحتوى          |                  أمام العلامة المائية (`z-index: 1`) |
| شعار الجهة في الرأس   | يبقى ظاهراً في رأس الصفحة كما في السابق |
| الاستقلال عن الشعار   | يظهر النمط النصي حتى عند غياب صورة الشعار |

## إعدادات النظام العامة

- يغيّر مالك المنصة فقط ظهور النمط المتكرر لعبارة `وزارة الداخلية`؛ إخفاء النمط لا يزيل اسم الوزارة الثابت من الترويسة الرسمية.
- يطبّق منزلق الشفافية النسبة نفسها على نمط النص وشعار الجهة، ضمن `0–60%` حفاظًا على وضوح محتوى البرقية.
- يضبط مالك المنصة لون خط الفصل أسفل الترويسة بصيغة Hex سداسية (`#RRGGBB`).
- خيار QR مركزي لجميع الجهات. إخفاءه يزيل الرمز من الوثيقة المطبوعة فقط ولا يعطل رابط التحقق.
- تحفظ القيم في `platform_document_settings` ويقتصر تحديثها على المالك مع سجل تدقيق؛ إعداد QR القديم للجهة باقٍ للتوافق فقط ولا يتحكم بالتصدير.

## قواعد الصفحة الواحدة

يجب أن تبقى ورقة التصدير داخل صفحة واحدة، مع إبقاء العلامة المائية داخل الورقة:

```css
.telegram-export-page {
  height: 297mm;
  min-height: 297mm;
  max-height: 297mm;
  overflow: hidden;
  break-inside: avoid;
  page-break-inside: avoid;
}
```

ويجب ألا يُستخدم `display: flex` على `body` لتوسيط الورقة؛ لأنه تسبب سابقًا في اختفاء المحتوى. التوسيط المعتمد هو:

```css
body {
  width: 100vw;
}

.telegram-export-page {
  width: 210mm;
  margin: 0 auto;
}
```

## قواعد PDF وPNG

- استخدام Chromium/Playwright server-side.
- استخدام `emulateMedia({ media: "print" })`.
- استخدام `@page { size: 210mm 297mm; margin: 0; }`.
- PDF:
  ```ts
  width: "210mm";
  height: "297mm";
  margin: 0;
  printBackground: true;
  preferCSSPageSize: false;
  ```
- PNG: تصوير لوحة A4 كاملة وليس عنصرًا داخليًا مقتطعًا، مع ضلع طويل مستهدف `7680px` (نحو 657 DPI على A4) وبيانات `pHYs` تعكس الكثافة الفعلية.
- لا يتغير تخطيط CSS أو أبعاد A4 بسبب رفع كثافة البكسلات؛ الناتج المتوقع نحو `5430 × 7680px`؛ لا تُضبط بيانات الدقة على قيمة أعلى من كثافة البكسلات الفعلية. هذه الصورة أقل استهلاكًا للذاكرة من هدف 1200 DPI السابق، لكنها ما تزال تتأثر بحدود ذاكرة المتصفح أو الخادم.
- تبقى عناصر النص والشعار وQR مرسومة من القالب نفسه؛ لا تُكبّر الصور الأصلية منخفضة الدقة اصطناعيًا. يحتفظ مسار تجهيز الشعار بتفاصيل أكثر (حتى 2400px على الضلع الأطول) قبل تضمينه.
- عدم استخدام `html2canvas` أو `jsPDF` لهذا المستند الرسمي.
- لا يجوز تغيير أبعاد الصفحة أو العلامة المائية اعتمادًا على المعاينة المصغرة في الهاتف.

## قواعد الطباعة من المتصفح

- `@page` بمقاس A4 عمودي وهوامش صفر. دقة إخراج الطابعة الفعلية تعتمد على تعريف الطابعة وإعداداتها، ولا يمكن ضمان دقة مادية محددة من CSS وحده. نص PDF المتجهي يظل قابلًا للطباعة بدقة الجهاز.
- حاوية الطباعة بعرض نافذة المتصفح.
- ورقة البرقية بعرض `210mm` وارتفاع `297mm` مع `margin: 0 auto`.
- عدم تغيير القيم المعتمدة في `getPrintStyles` دون مقارنة الناتج بالطباعة الحالية.
