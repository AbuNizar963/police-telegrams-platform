# خدمة PaddleOCR-VL الخاصة

هذه خدمة مرافقة خاصة لمنصة البرقيات. تشغّل **PaddleOCR-VL** المفتوح المصدر محليًا أو على خادم GPU خاص، ولا تحفظ الصور أو النصوص؛ تكتب الصورة في ملف مؤقت وتحذفه بعد الاستدلال.

## التشغيل

يلزم خادم Linux مزوّد بـ NVIDIA GPU وDocker مع `nvidia-container-toolkit`.

```bash
cd ai-input-service
docker build -t police-paddleocr-vl .
docker run --rm --gpus all -p 127.0.0.1:8080:8080 \
  -e AI_INPUT_SERVICE_TOKEN='ضع-سرًا-طويلًا-هنا' \
  police-paddleocr-vl
```

تحقق من الجاهزية:

```bash
curl http://127.0.0.1:8080/health
```

## ربط المنصة

أضف القيم التالية في **بيئة الخادم فقط** (محليًا في `.env`، وعلى Vercel في Environment Variables). لا تبدأ أي قيمة بـ `VITE_` حتى لا تُرسل إلى المتصفح:

```bash
COHERE_API_KEY=مفتاح_Cohere_المجاني_ذو_الحدود
PADDLEOCR_VL_URL=https://اسم-الخدمة-الداخلية.example
AI_INPUT_SERVICE_TOKEN=نفس-السر-المستخدم-في-الحاوية
```

- `COHERE_API_KEY` يفعّل تفريغ **Cohere Transcribe Arabic** العالي الدقة. يمكن الحصول على مفتاح تجريبي مجاني محدود المعدل من Cohere.
- `PADDLEOCR_VL_URL` يجب أن يكون عنوانًا خاصًا/داخليًا لخدمة الحاوية؛ لا تُعرّض `/ocr` للعامة. `AI_INPUT_SERVICE_TOKEN` إلزامي في الجانبين: ترفض الخدمة البدء بدونه، وترفض كل طلب لا يحمل المصادقة المطابقة.
- إذا لم تُضبط قيمة ما، تظل الواجهة عاملة ببديل المتصفح المحلي: Web Speech للصوت وTesseract للصورة.

## الحدود والخصوصية

- تقبل الخدمة صور JPEG وPNG وWebP حتى 10 ميغابايت و40 مليون بكسل، وتتحقق من بصمة الملف ومطابقة نوعه قبل تمريره للموديل.
- يستقبل الخادم التطبيقَ الصورة أو الصوت من المستخدم الموثق فقط، ويحوّلها فورًا إلى مزود النموذج؛ لا تُخزَّن مادة الإدخال في قاعدة بيانات المنصة أو Supabase Storage.
- احتفِظ بالخدمة في شبكة خاصة. لا تستخدم رابطًا عامًا غير محمي للوثائق والبرقيات الشرطية.
- أوزان النموذجين مجانية ومفتوحة المصدر، لكن تشغيل GPU أو استضافة خادم قد تكون له كلفة بنية تحتية؛ لا يوجد ادعاء بأن العتاد أو الشبكة مجانيان.
